# AI Editing Guide

## Purpose

This repository is the public GitHub profile for `tocsindata`. Root `README.md` is the product surface; it is not an application README.

## Invariants

- Preserve the professional biography, capabilities, testimonial, contact information, and technical skills unless the current task explicitly changes them.
- Maintain the root README as readable public profile content; keep repository documentation links after the profile content.
- Do not convert the profile into an application or organization-wide registry.
- Do not add private facts, secrets, operational identifiers, speculative achievements, unverifiable claims, or unrelated repository details.
- Preserve attribution and exact meaning when editing testimonial material.
- Keep the existing PNG and SVG assets unchanged unless image work is explicitly authorized.
- Treat `tocsindata.com` as an associated contact domain, not as a deployment controlled by this repository.
- Do not infer authorization for Slack, Matomo, DNS, hosting, other repositories, or production systems.

## Verification

For Markdown changes, validate the three allowed root Markdown files, canonical documentation paths, internal links, metadata fields, public rendering intent, and Markdown-only scope.
