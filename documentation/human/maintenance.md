# Maintenance

## Routine Review

1. Confirm the biography, experience, skills, availability, testimonial attribution, and contact information remain accurate.
2. Verify the README renders correctly on the public GitHub profile.
3. Check that the email link and documentation links resolve.
4. Confirm the PNG and SVG branding assets are intentional and safe for public use.
5. Reverify the associated `tocsindata.com` Matomo mapping only from exact `#webstats` evidence when the domain relationship changes.
6. Update `meta.md`, history, and central TODO evidence after material changes.

This repository does not deploy the `tocsindata.com` website. No application release, server update, database migration, or runtime procedure applies.
