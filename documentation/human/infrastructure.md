# Infrastructure

## Repository Surface

GitHub hosts the repository and renders root `README.md` on `https://github.com/tocsindata`. There is no application runtime, server, database, dependency installation, scheduled job, or deployment configuration in this repository.

## Associated Domain Evidence

The README publishes `info@tocsindata.com` as the contact address. Exact `#webstats` evidence dated 2026-09-15 maps `https://tocsindata.com` to Matomo site ID 2 with site name `Tocsin Data`.

The domain's DNS, hosting, registrar, expiry, website source repository, and deployment process are not established by this repository and remain outside its scope.
