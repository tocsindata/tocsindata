# Security

## Classification

This is a Level 0 public repository intended to publish Dan's professional profile. Everything committed here must be suitable for public disclosure.

## Rules

- Do not add secrets, internal infrastructure, private client details, protected operational data, non-public contact details, or confidential employment material.
- Verify claims, dates, capabilities, quotations, names, links, and contact information before publication.
- Obtain appropriate authority before materially changing or removing attributed testimonial text.
- Keep images free of hidden sensitive metadata when new assets are introduced.
- Treat the profile email as public contact information, not authentication material.
- Do not infer authorization to edit the associated domain, Slack, analytics, or other repositories.

The supply-chain policy is retained for repository-wide governance even though this repository contains no executable software.
